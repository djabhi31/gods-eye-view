## ⚡ 30-Second Quickstart

Experience the full tactical console on your local machine in three commands:

```bash
# 1. Clone the repository
git clone https://github.com/djabhi31/gods-eye-view.git
cd gods-eye-view

# 2. Install dependencies (Node >=24.14.0 or Node 22 LTS)
npm install

# 3. Launch the high-speed local dev server
npm run dev
```

Open **`http://localhost:4173`** in Chrome, Edge, or Brave. All baseline layers operate immediately with zero configuration!

## 🚀 Cloud Edition Architecture

Designed by **[Abhilash Ghosh](https://github.com/djabhi31)** to deliver a zero-friction, production-grade cloud deployment:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                    CLIENT BROWSER                                      │
│  • CesiumJS Photorealistic 3D Engine & Google 3D Tiles                                  │
│  • Browser-Isolated BYOK (localStorage: Cesium, Google Maps, OpenAI, AISStream)        │
│  • WebGL / GLSL Post-Processing Pipeline (FLIR / NVG / CRT / Noir)                     │
└───────────────────────────┬────────────────────────────────────────▲───────────────────┘
                            │ HTTPS / WSS                            │ HTTP/2 Assets &
                            │                                        │ Telemetry Data
┌───────────────────────────▼────────────────────────────────────────┴───────────────────┐
│                    MICROSOFT AZURE APP SERVICE / LINUX CONTAINER                       │
│                                                                                        │
│  [ Production Web Server: server.mjs ]                                                 │
│  • High-throughput HTTP/2 asset delivery with Brotli / Gzip compression                │
│  • Single Page Application (SPA) HTML5 routing fallback                                │
│  • Automatic heartbeat & readiness probe at /api/health                                │
│  • Zero-secret server state — no visitor API credentials touch server disk             │
│  • Hardened reverse-proxy boundaries preventing SSRF attacks                           │
└───────────────────────────┬────────────────────────────────────────────────────────────┘
                            │
     ┌──────────────────────┼──────────────────────┬──────────────────────┐
     ▼                      ▼                      ▼                      ▼
[OpenSky ADS-B]      [AISStream AIS]        [CelesTrak TLE]        [NASA FIRMS]
11,000+ Flights      Maritime Vessels       Orbital Telemetry      Active Wildfires
```

### Key Engineering Upgrades:
1. **Lightweight Cloud Server (`server.mjs`):** Production-ready HTTP/2 server serving optimized static bundles with MIME classification and graceful teardown.
2. **Browser-Isolated BYOK (Bring Your Own Key):** Replaced server-side credentials with client-side `localStorage`. Every visitor brings their own free tokens without quota leaks.
3. **Always-On Azure Cloud Infrastructure:** Engineered for zero cold starts on Microsoft Azure App Service with custom CNAME and auto-renewing SSL at **[godseyeview.earthsphere.in](https://godseyeview.earthsphere.in)**.
4. **EarthSphere Geospatial Pairing:** Serves as the high-fidelity 3D tactical companion to the **[EarthSphere](https://github.com/djabhi31/EarthSphere)** environmental suite.
5. **Zero-Leak Security Audit:** 100% clean security posture backed by hardened `.gitignore` blocking private keys and certificates.
6. **Sits on the real ground.** Entity heights are aligned to work with Google 3D tiles, so aircraft park on aprons and cameras stand on street corners instead of floating.

### 🟢 Free Deployment (Render.com)

Render offers a 100% free web service tier with automated HTTPS:

1. **Fork this repository** to your GitHub account.
2. Go to [dashboard.render.com](https://dashboard.render.com/) ➔ **New +** ➔ **Web Service**.
3. Connect your fork and set:
   - **Runtime**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `node server.mjs`
   - **Instance Type**: `Free`
4. Add environment variables: `PORT=4173`, `NODE_ENV=production`.
5. Click **Create Web Service**. Your app is live in ~3 minutes!

> [!TIP]
> **Preventing Free Cold Starts**: Free instances sleep after 15 minutes of inactivity. Set up a free heartbeat check on [UptimeRobot](https://uptimerobot.com/) targeting `https://<your-app>.onrender.com/api/health` every 10 minutes to keep your container awake.

### 🔵 Paid Cloud Deployment (Microsoft Azure App Service)

This is the **exact enterprise setup** powering [godseyeview.earthsphere.in](https://godseyeview.earthsphere.in):

```bash
# 1. Login to Azure CLI
az login

# 2. Create Resource Group
az group create --name RG-EarthSphere-Production --location centralindia

# 3. Provision Linux App Service Plan (B1 Basic - ~₹1,100 / $13 per month)
az appservice plan create \
  --name Plan-GodsEyeView-B1 \
  --resource-group RG-EarthSphere-Production \
  --location centralindia \
  --is-linux \
  --sku B1

# 4. Create Web App
az webapp create \
  --name godseyeview \
  --resource-group RG-EarthSphere-Production \
  --plan Plan-GodsEyeView-B1 \
  --runtime "NODE:22-lts" \
  --startup-file "node server.mjs"

# 5. Enable Always-On & HTTP/2 (Eliminates cold starts completely)
az webapp config set \
  --name godseyeview \
  --resource-group RG-EarthSphere-Production \
  --always-on true \
  --http20-enabled true
```

## 📋 Responsible OSINT Charter

God's Eye View is designed strictly for **situational awareness, environmental monitoring, scientific inquiry, and educational open-source intelligence (OSINT)**.

- **Infrastructure Telemetry Only:** Exclusively models publicly broadcast signals (ADS-B, AIS, TLE, seismographs, public DOT cameras).
- **Zero Individual Surveillance:** Features zero facial recognition, private vehicle tracking, or personally identifiable data gathering.
- **Safety Advisory:** Telemetry may be simulated or latency-buffered. Do not use for actual flight navigation or maritime steering.
